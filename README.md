# RV Resort Website

A single-page static showcase site for RV Resort, built with plain HTML and CSS (no framework or build step).

## What it includes

- A hero header with the resort name and a call-to-action to call or get directions
- A grid of resort highlights/amenities
- A photo gallery of the property
- A video walkthrough of the resort
- A location and contact section

## Running locally

This is a static site with no build step. Open `index.html` directly in a browser, or serve the repo root with any static file server, e.g.:

```bash
npx serve .
```

## Deployment

Deploys as-is on Netlify as a static site — no build command is required.
